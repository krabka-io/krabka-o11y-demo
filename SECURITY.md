# Security policy

Report vulnerabilities privately through GitHub's **Security advisories → New
draft advisory** page for `krabka-io/krabka-o11y-demo`. Do not open a public
issue for a suspected vulnerability.

The maintainers will acknowledge a report within three business days, assess
impact, coordinate a fix, and publish an advisory when users can update. Include
the affected revision or image digest, reproduction steps, and potential
impact. This demo binds published ports to loopback by default; operators who
override that setting are responsible for network access controls.
